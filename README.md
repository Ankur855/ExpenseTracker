# Expense Tracker App (React Native)

A feature-rich **Expense Tracker** built with **React Native**, using **React Query**, **Axios**, and **React Hook Form** for API integration and form handling.

---

## 📦 Features

- View, add, edit, and delete expenses
- Offline caching with React Query
- Optimistic updates for a smooth UX
- Form validation using React Hook Form
- Floating action button to add expenses
- Dashboard with total and today’s expenses
- Simple and responsive UI

---

## 🛠 Tech Stack

- **React Native CLI**
- **TypeScript**
- **React Navigation**
- **@tanstack/react-query**
- **Axios**
- **React Hook Form**
- **Vector Icons**
- **iOS & Android support**
